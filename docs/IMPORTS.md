# Historical Imports

Historical imports are optional. Their purpose is to seed a Project Space with older ChatGPT or Gemini history.

## Rule

Archive source files first, parse second. If an export format changes, the original export remains available for a future parser.

## Supported targets

- ChatGPT export
- Gemini / Google export preservation, with provider-specific parsing added incrementally as validated

The UI accepts an extracted export folder. Direct ZIP handling can be added later.
